### v0.2 任务链路（应用侧的全部数据面）

「任务下发 → lite 取任务 → 交付 → 回写」经本服务即全部，客户端仍单依赖（studio 已单用户化，不设派发界面）：

- [ ] 任务下发：任务实例（来源待定）→ lite 拉取（按 learner 投影今日任务卡）
- [ ] 交付提交：lite 提交 → studio 批改面收取
- [ ] 任务状态回写：派发 / 提交 / 退回重做 / 通过，落仓内任务模型
- [ ] 单元并入任务：课程 = 任务序列，任务 = 小需求 + 动作 + 判定 + 反馈；每任务挂一条 criterion
- [ ] 任务书与任务实例分离：任务书仓内版本化（修订 = 分叉、合稿 = 裁决），实例 = 派发记录——修订不改实例，回灌不丢轨迹
- [ ] 仓内自持三线：内容数据文件进仓（与 site 同源）、自带存储（learner × criterion）、任务模型仓内定义（契约按 studio 静态数据先行验证）
- [ ] 状态表即流程定义：状态迁移逐个接口守卫，不允许绕过

数据模型约束（真实业务已发生，模型必须承载）：任务关联订单来源；交付前经不同机器 / 系统验证；报名为周期性意愿确认；记录行动与其效果的对应关系。
