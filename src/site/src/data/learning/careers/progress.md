# 成长进度条

以负数职级标示相对公司招聘标准的位置：

| 职级 | 含义 |
|---|---|
| -3 | 纯学员，尚未参与实际贡献 |
| -2 | 可参与一些小的贡献 |
| -1 | 可较独立地参与贡献 |
| **0** | 可入职（获得公司身份） |

负数是"商场地下楼层"，不代表能力是负的——它是每个人从首次参与到获得公司身份的可见路径。

定档与晋升由真实贡献决定；表现优秀者可被任命为代表，参与课题评审等基地治理（有报酬，见任务与价格说明）。
