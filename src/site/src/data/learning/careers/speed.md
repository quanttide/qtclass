# 成长速度参考

- 长期参与 **3-6 个月**，毕业时工作能力普遍高于同龄人一大截。历史案例：一位同学参与半年后，其同学看到他的成长，一人带来十几二十人。
- 当前平均已被压缩到 **3 个月**；特别突出者 **1-2 个月**即可飞速成长——有同学在 1 个月内开始接手整个产品线的负责工作。
- 组队参与提高录取率：**更倾向于直接录取已经磨合好的团队**。产品/技术方向建议与商务方向学员互相搭档，互相补齐甲方视角。

速度由贡献决定，不由时长决定。
