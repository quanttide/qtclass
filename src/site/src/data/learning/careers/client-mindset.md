# 甲方思维

贯穿全部学习方向的训练主线。

- 捕捉真实需求是最稀缺的能力——"**最贵的东西永远都是真实的需求**"。
- 不调研甲方而凭市场常识猜测，做出的东西大概率"是已试过且不好用的"。
- 需求大小取决于如何解释——同样的需求，解释得好是大需求，否则是小需求；甲方难以愿意为小需求投入资源。企业服务市场必须学会包装需求。
- 企业视角看课题申请：要能回答"为什么这东西能帮我们赚钱"。
- 群聊沟通是训练的一部分：不提问、不沟通就过不了——建群的目的就是给候选人直接沟通的窗口。

产品/技术方向与商务方向的学员互相搭档，是训练甲方思维的最好方式——也是我们推荐组队的原因之一。
