# 智能体工程师训练营

面向需要以 AI 智能体方式开展研发、自动化与交付的成员，主线是建设数据工程第二大脑（从熟悉体系、考古意图、梳理洞察到排定路线图），训练从工具使用到方法论自觉的能力。

## Task 1：熟悉量潮数据工程第二大脑

以新人视角通读数据工程领域第二大脑（quanttide-data 主仓库、资产图式章程、发布管理章程），记录「知识诅咒」视角下的困惑，并提出改进建议。达成：至少一条建议经 Issue 讨论达成共识后进入 PR。

来源：tasks/data-second-brain.md

## Task 2：整理数据工程意图

从数据工程日志（journal）出发，参考现有意图文档格式，增加 qtcloud-data 和 qtdata 的最新想法，描绘量潮为什么想建设数据工程第二大脑。达成：意图文档更新稿经 Issue 讨论后进入 PR。

来源：tasks/data-intention.md

## Task 3：整理数据工程洞察

把数据工程语境（context）中与 AI 协作产生的随手记录梳理成关键洞察，参考教程与札记搭建信息结构。达成：洞察结构与关键洞察成稿，建模想法经 Issue 讨论后进入 PR。

来源：tasks/data-insight.md

## Task 4：更新数据工程路线图

根据整理好的意图与洞察更新路线图，回答下一步做什么，分类排期后成为可进入开发流程的 ROADMAP。达成：路线图更新稿经 Issue 讨论后进入 PR。

来源：tasks/data-roadmap.md

## Task 5：贡献学习档案

从自己的角度梳理在量潮课堂的学习历程，与团队一起补充完善，帮助建立学习管理体系。达成：档案文件更新并提交（含可公开内容即可）。

来源：tasks/learn-profile.md

## Task 6：文档工程章程升级（智能体工程师与产品经理共有）

把使用《文档工程格式章程》的真实感受带回来，升级成「社区版」。达成：对照章程提出顺手/困惑/建议，讨论达成共识后更新章程文件。

来源：tasks/docs-bylaw.md
