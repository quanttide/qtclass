# 共识链识别实验

沟通云的核心功能是「共识链条」——把高频变动的讨论显式整理成大家共同认同的共识。我们想请你做一次概念验证（PoC）：验证「共识链」可以被大模型识别。

## 背景

「共识」表达的是大家共同认同的东西。共识链条把讨论中依次形成的共识串起来：

- 解决信息记录问题：看大家共同认可了什么，就把信息统一和简化了，可以快速对齐各方想法、明确项目状态
- 「悬而未决」也可以是一种共识：有些本应形成共识、但一直没有被明确确认的东西，同样记录为一种共识状态（「我们搞不定，所以要摇人」）

内部团队做这件事的原因：团队内部的整理能力跟不上这么高频的消息变更速度；希望通过显式展示「共识链条」的变化，同步内外部的信息，把这种高频的变化串起来。

## 步骤

1. 复制本群（或任一真实讨论群）的一段讨论内容
2. 在电脑端打开任意网页版大模型
3. 让模型「提取这段聊天记录里讨论者们依次形成的共识」
4. 检查提取结果：是否还原了讨论中依次形成的共识链条？「悬而未决」这类共识是否被识别？

## 交付与提交方式

讨论与产出提交到量潮沟通管理实验室：https://github.com/quanttide/quanttide-laboratory-of-communication-management

1. 在 Issue 中分享你的验证结果：提取出的共识链条、识别失败或遗漏的案例、对共识链建模的想法
2. 讨论达成共识后提交 PR，并在 PR 中引用该 Issue
3. PR 通过后关闭 Issue

如果你对 Issue 和 PR 操作不熟悉，不用紧张——在 Issue 中说明自己不会操作即可，我们会安排人或陪你一起完成这一步。

## 重要提醒

- 这是概念验证，随时都可以验证，不需要完整方案
- 用真实讨论内容验证，越接近实际使用场景越好
