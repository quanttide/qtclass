# 更新数据工程路线图

请根据整理好的意图和洞察，更新数据工程路线图（roadmap）。

## 路线图的定位

路线图是「未来的事件记忆」，它的主要功能是回答下一步要做什么——这也是给你自己和团队未来的工作清单。它经过分类和排期以后，就可以成为某个具体仓库的 ROADMAP 文件，方便进入正式的开发流程。

## 步骤

1. 阅读现有路线图：https://github.com/quanttide/quanttide-roadmap-of-data-engineering
2. 结合数据工程意图与洞察，更新路线图：
   - 意图：https://github.com/quanttide/quanttide-intention-of-data-engineering
   - 洞察：https://github.com/quanttide/quanttide-insight-of-data-engineering
3. 按下方提交方式与团队沟通你的整理结果

## 提交方式

讨论与产出提交到数据工程路线图仓库：https://github.com/quanttide/quanttide-roadmap-of-data-engineering

1. 先在 Issue 中提出你的想法，与团队讨论达成共识
2. 共识后提交 PR，并在 PR 中引用该 Issue
3. PR 通过后关闭 Issue

如果你对 Issue 和 PR 操作不熟悉，不用紧张——在 Issue 中说明自己不会操作即可，我们会安排人或陪你一起完成这一步。

## 进度汇报

请向本邮箱汇报正式进度。抄送的两个邮箱分别为公司秘书处和数据业务部门维护，他们分别作为支持方提供管理和业务信息。
