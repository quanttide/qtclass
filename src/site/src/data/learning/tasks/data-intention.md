# 整理数据工程意图

数据工程的意图文档目前停留在前一阶段的设计，新阶段已经积累了很多新想法。我们想请你从数据工程日志（journal）出发，把意图文档更新到最新。

## 意图的定位

意图是「未来的自我记忆」，关系到组织希望成为一个什么样的组织。它们一般相对稳定，但是和组织自己高度绑定，不一定具备很强的迁移性。

## 步骤

1. 阅读现有意图文档，熟悉格式与内容：https://github.com/quanttide/quanttide-intention-of-data-engineering
2. 通读数据工程日志：https://github.com/quanttide/quanttide-journal-of-data-engineering
3. 参考现有意图文档的格式和内容，增加 qtcloud-data 和 qtdata 的最新想法
4. 整理完成后，按下方提交方式与团队沟通你的结果

## 提交方式

讨论与产出提交到数据工程意图仓库：https://github.com/quanttide/quanttide-intention-of-data-engineering

1. 先在 Issue 中提出你的想法，与团队讨论达成共识
2. 共识后提交 PR，并在 PR 中引用该 Issue
3. PR 通过后关闭 Issue

如果你对 Issue 和 PR 操作不熟悉，不用紧张——在 Issue 中说明自己不会操作即可，我们会安排人或陪你一起完成这一步。

## 重要提醒

- 日志不是唯一的信息来源，你也可以直接从原始代码中获取信息并推测意图
- 最终目标是描绘量潮为什么想要建设这样一个数据工程第二大脑——日志只是一种比较重要的信息来源
