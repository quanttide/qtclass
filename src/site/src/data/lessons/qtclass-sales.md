# 量潮课堂销售指南

## 为什么我们的销售不一样

和教育机构的传统招生不同，我们的销售不是「学生来咨询 → 我们介绍课程 → 学生报名」这条单向路径。我们卖的也不只是一门课。

量潮的产品是一条完整的成长路径：学员阶段系统学习，实训阶段参与真实项目，实习阶段获得正式聘用；课堂学员和招聘申请者共用一套考核方式，学完能拿到可验证的信用证明——考核记录、导师评价、标准化推荐信。课程只是这条路径的第一站，销售要讲的是整条路径。

我们的学生画像很特殊——优质但小众。如果不精准触达、不按销售转化的逻辑来，光靠课程介绍是转不动的。

## 学生画像：优质但小众

### 优质在哪里

优质的学生在学习上有付费习惯，愿意为提升自己花钱。他们大多踩过坑——接触过的大部分课程或服务质量都不好，有比较才有鉴别，对比之下反而能感受到我们的服务质量。他们主动性强，会自己找资源、自己提问、自己跟进。

### 小众在哪里

这类学生在主流市场上并不常见。大部分人没有付费学习的习惯，或者只愿意为「证书/学历」付费。愿意为「能力提升」付费、且能识别质量差异的人，本身就是一个筛选过的群体。

一句话画像：在学习上花过钱、踩过坑、能识别好坏、愿意主动学的人。

### 另一类人：想证明自己的人

除了想学的人，还有一类人值得关注：求职者、实训候选人、招聘申请者。他们不一定需要课程，但需要证明自己——一份可验证的考核记录、一封来自真实企业的推荐信。这类人和学员共用同一套考核体系，只是分数线的区别。对这类人，销售讲的不是课程，而是「我们怎么帮你证明自己」。

反过来，什么人不是我们的目标：只问价格不问内容的人、等着被喂不主动参与的人、认为教育应该免费的人、为「拿证」而不是「学会」来的人。遇到这些人，不需要浪费时间。

## 怎么找到他们：定向触达

因为群体小众，广撒网效率很低，需要定向触达。渠道按优先级排序：

1. 现有学员推荐/转介绍——画像最准，信任成本最低
2. 高校合作渠道（如浙理工）——有学校背书，批量触达
3. 众包平台（crowd.quanttide.com）——学员参与真实项目，自我选择分流，天然筛出愿意干活的人
4. 招聘渠道——公开考核题、招聘公告本身就是市场触达，吸引想证明自己的人
5. 技术社区/开源社区——主动学习者聚集地
6. 就业焦虑场景（招聘平台、求职群）——痛点明确，转化路径短
7. 大众广告/信息流——效率最低，不推荐早期使用

触达之后，不要让销售在「这个人是不是目标用户」上靠感觉。用几个快筛问题：你之前为学习花过钱吗？花在什么地方？你觉得之前那些课程怎么样，为什么不满意？你这次想学，是想要一个证书，还是想真的掌握这个能力？你每周能花多少时间在学习上？

前三个问题筛画像，第四个问题筛履约能力。

## 从触达到转化：销售的完整链路

这是我们和当前团队最大的认知差：「说服用户上课」和「完成销售转化」是两件事。

说服上课，目标是让用户觉得课程不错，结束标志是用户说「好的我考虑一下」。销售转化，目标是让用户完成下单、上课、完课的完整闭环，结束标志是用户付款、上完第一节课、续费或推荐。前者只负责介绍课程，后者要覆盖售前、售中、售后全流程。

转化的完整链路是：

触达 → 建立信任 → 确认画像 → 展示匹配价值 → 促成下单 → 履约跟进 → 信用交付 → 续费/转介绍

每一层都有明确的动作和判断标准。触达，让学生知道我们存在，判断标准是对方愿意继续聊而不是已读不回。建立信任，展示真实案例和开放试听，判断标准是对方开始主动提问。确认画像，用快筛问题判断是否目标用户，不符合就不浪费精力。展示匹配价值，针对对方的痛点具体说明课程怎么解决——不要背参数（「我们有 XX 课时」），要说结果（「上一期学员结业后 X 周内拿到了面试」）；对想证明自己的人，讲信用交付——考核记录、导师评价、推荐信都可以公开验证。促成下单，明确报价、服务内容、交付时间表，消除顾虑（担心学不会 → 有助教跟进；担心没时间 → 弹性学习安排）。履约跟进，开课提醒、进度跟踪、问题响应——完课率直接影响续费和口碑，付了钱不等于结束。信用交付，课程结束时主动产出可验证的成果：考核记录、评价、推荐信——这是量潮独有的交付物，学员带走的不只是知识，还有证明。续费/转介绍，课程结束时主动询问体验反馈，引导推荐。

常见的错误是这四个：见人就推不筛画像；讲完课程就等对方主动；付款后就不管了；不敢报价怕人跑了。对应的纠正分别是：先筛画像再花时间、每个接触点都要有「下一步」、履约跟进和售前一样重要、报价越早明确越好。

## 团队意识建设

销售不是「销售岗位」的事，课程团队每个人都需要建立商业化意识。需要反复强调三句话：

1. 我们是一个商业化的课程团队，不是公益教育组织。课程质量好是基础，但质量好不等于自动有人来买，主动做销售转化是每个人的职责。
2. 画像不明确的触达是浪费双方时间。跟一个不合适的人聊三天，不如花三天找到两个对的人。
3. 用户付了钱只是开始。完课率和满意度决定了这个用户会不会带来下一个用户，履约跟进和售前一样重要。

市场人难找是整个公司的共识——技术和产品都好招，市场人才太少。所以销售意识不能只长在销售岗位上，每个业务线都要自带获客属性：课程的教学即营销，招聘的公开考核题即营销，众包的任务即营销。

每周复盘问四个问题：这周触达了多少人，其中几个符合画像？转化率多少，哪个环节流失最多？流失是话术、价格、信任的问题，还是画像筛选没做好？有没有特别满意的用户案例可以复用？
