# 发送准入问卷

本教程说明招聘流程中「发送准入问卷」这一步怎么做、为什么这么做、哪些地方要判断。

## 这一步在流程中的位置

投递筛选 → **发送准入问卷** → 回收问卷 → 初筛评估 → 面试

问卷是筛选的第一道门槛。为什么是问卷而不是别的？

因为简历不可信。简历是候选人自己写的，写的是「他想让我们看到的样子」；而且大量投递是海投，简历质量参差不齐，靠简历做初筛等于靠运气。问卷则要求候选人付出真实的时间——认真填一份问卷需要投入，这份投入本身就是态度的信号。我们考核的核心是候选人是否积极思考和参与讨论，问卷看的就是这个：能不能认真理解问题、组织回答。

问卷也是候选人对我们的第一次体验。流程是否专业、说明是否清晰，决定了候选人怎么看待这家公司。这一步做得好，后面的沟通成本都会降低。

候选人完成问卷后，我们才有足够的信息做初筛判断。未在 3 个工作日内提交的，视为放弃——连问卷都不按时交的人，入职后更不可能主动，时间投入是履约能力的第一个证据。

## 发送时机：为什么当天发

收到投递后尽快发送，最好当天。候选人在投递那一刻热度最高，拖一天热情就淡一分，甚至可能已经接受了别家——优秀候选人同时投好几家，先到先得。拖久了还意味着积压：投递量大的时候，积压会让最先投递、最认真的候选人等最久，这是对认真的惩罚。

## 操作方法

### 1. 确认候选人信息

从 HR 邮箱的投递邮件中提取三项信息：姓名（后续所有沟通用的名字）、邮箱（发送问卷的目标地址）、岗位（确认投递的是哪个岗位）。邮件主题通常包含候选人姓名、岗位和实习时长，例如「数据工程师-张三-清华大学-6个月」。

为什么信息不全不要发：邮箱是我们和候选人之间唯一的触点，写错了联系不上，等于白白浪费一次触达；岗位弄错了，问卷内容就不匹配，候选人会觉得我们不专业。缺少邮箱或岗位时，先在邮件列表里翻找或等待补充。

### 2. 确认问卷链接

问卷链接从 HR 邮箱的缓存中读取，发送前先确认链接是否就绪。没有链接或链接过期时，刷新缓存重新获取后再发送。

链接过期是常见事故：候选人点开链接发现失效，第一反应是怀疑这家公司的专业性。发出去之前确认一次，比发出去之后补救便宜得多。

### 3. 发送问卷

向候选人邮箱发送问卷通知邮件，发送方统一为 `hr@quanttide.com`。统一发件人有两个原因：候选人侧，来自固定邮箱的通知可信，不会被认为是诈骗邮件；我们侧，所有问卷往来集中在一个邮箱，出了问题可追溯、可查询。

发送后投递邮件自动归档到「已发送问卷」文件夹并标注已读。投递量大的时候，不归档就会重复处理——同一个候选人收到两封问卷，是招聘里最尴尬的事故之一。

### 4. 验证发送

发送后核对结果：确认已发送标志和收件人信息正确。

发送失败是不自知的：候选人没收到，我们不知道，流程就静默中断了——候选人以为我们不理他，我们以为他在拖。验证的代价是几秒钟，静默中断的代价是失去一个候选人。验证通过才算是完成了这一步，不要发完就关掉。
