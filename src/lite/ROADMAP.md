# ROADMAP — qtclass-lite

学员任务系统（被动端）：首屏任务卡，无选择、无导航、无配置；课程与实训都是任务序列。用户不问付费方——在学的都在这里，付费个人的客户面在 studio。

## 前置（未就绪不立项）

- studio v0.2：没有派任务，首屏就是空的
- provider v0.2 任务链路（仓内自持，不依赖学习云）

### v0.2 任务系统成型

- [ ] 任务列表：有序、过门槛（完成上一任务解锁下一任务）
- [ ] 任务状态机：待做 / 进行 / 已交 / 退回 / 通过，首屏只突出当前任务
- [ ] 题面嵌媒体：任务详情内嵌播放件（Taro 内嵌，不是播放器）
- [ ] AI 即时判定：自由作答 AI 判定给反馈，教师异步批改兜底；作答与反馈数据是淘汰赛与教学改进的凭据
- [ ] 数据经 provider：每任务挂一条 criterion 回写；素材源两条线——真业务线供题（游戏、小说发行）+ qtdata 复现项目

### 明确不做

选课、课表浏览、课程目录、任何配置项；不让学员选择"做什么"——被动指派，主动判断（任务内的选择属任务动作，不属导航自由度）。

### 技术通道

对齐 qtcloud lite（Taro 多端），不另行选型；发布复用 miniprogram-ci 模式。页面蓝本 studio `doc/screens/`——代码不过端，契约过端。
