# ROADMAP — qtclass-lite

学员任务系统（被动端）：首屏任务卡，无选择、无导航、无配置；课程与实训都是任务序列。用户不问付费方——在学的都在这里，付费个人的客户面在 studio。

现状：**Web 首切片落地**——React + Vite（与 site 同构；原 Taro 方向随「不发小程序，直接发 web」调整）；三页（今日任务卡 / 任务详情 / 反馈）、任务契约静态层、任务书 10 篇迁入 `data/tasks/`，首任务 = 任务书修订；`deploy-lite.yml`（`lite/*` tag → OSS + CDN）已备，待 bucket 与子域开通后首发。

## 前置
