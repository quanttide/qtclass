# ROADMAP — qtclass-lite

学员任务系统（被动端）：微信式外壳——顶部 AppBar、底部三页签（理论 / 实践 / 我的），实践页以两把尺筛选任务书。用户不问付费方——在学的都在这里，付费个人的客户面在 studio。

现状：**页签外壳 + 两把尺落地**——三页签（理论 / 实践 / 我的）+ 压入页（任务详情 / 反馈）；任务书 12 篇全量标注 `tags.requirement / acceptance`，实践页单入口底部弹层筛选（模糊/半精确/精确 × 封闭/半开放/开放）；课程清单自 site 迁入理论页；`deploy-lite.yml` 已首发（`lite.class.quanttide.com`）。
