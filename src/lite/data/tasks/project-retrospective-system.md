# 项目复盘系统搭建
- 业务：项目管理
- 类别：工作流搭建
- 状态：进行中

## 任务背景

量潮已经形成项目复盘章程、方法论和案例结构。现在需要把这些规范整理成一个可填写、可审核、可归档、可跟踪行动项的项目复盘系统，供商务经理、软件工程师、项目经理和审核人协作使用。

本任务的公开档案只描述通用流程和交付要求。涉及具体项目的内部材料，报名后由任务负责人按权限提供，不得自行扩散。

## 任务内容

1. 阅读项目复盘章程、方法论和公开案例结构，整理系统字段和状态流转；
2. 完善复盘工作台，支持任务创建、角色分工、证据登记、沟通复盘、流程复盘、技术实操复盘、汇总核验、负责人确认、审核签发、归档和行动跟踪；
3. 支持保存草稿、生成 Markdown、下载正式版和公开脱敏版；
4. 区分事实、分析、推测和待确认事项，为重要结论登记证据来源和日期；
5. 编写非技术成员使用说明、检查清单和后续成果回写规则；
6. 完成端到端测试，记录已知问题和后续改进建议。

## 任务输入

- 项目复盘工作章程；
- 项目复盘方法论教程；
- 项目复盘公开案例结构；
- 报名后按权限提供的脱敏项目材料；
- 报名后由任务负责人提供的工作台访问方式和验收说明。

## 交付物

- 可运行的项目复盘工作台或对现有工作台的可验证改进；
- 复盘流程、角色、状态、审核签发、归档、行动跟踪和成果回写说明；
- 一份经过人工复核的公开脱敏版导出示例；
- 非技术用户使用说明和复盘检查清单；
- 可复现的页面、脚本和端到端测试记录；
- 交付地址和代码仓库由任务负责人按权限确认。

## 验收标准

- 覆盖沟通、流程、实操三条复盘线和六部分报告结构；
- 技术交付人员与技术复盘人员可以分别登记；
- 重要结论支持事实、分析、推测、待确认四种类型，并登记证据来源和日期；
- 空字段保持为空，不生成无证据的“客户满意”“基本顺利”“按期完成”等判断；
- 支持保存草稿、生成 Markdown、下载文件、清空表单和维护行动项；
- 公开版不包含客户名称、人名、内部路径、聊天内容、密钥、Token、密码或私钥；
- 完成一轮可复现的页面和脚本测试，并记录已知问题。
