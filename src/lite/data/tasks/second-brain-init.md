# 第二大脑创建插件

- 业务：量潮云
- 类别：招聘考核
- 状态：进行中

## 任务背景

我们有一套用于创建「第二大脑」上下文的对话流程，已配套格式章程，AI 能稳定遵循；近期由非技术成员按说明操作，已跑通无误。现提供该对话的原始导出文件，希望将其接入资产云，整理为插件 / 可复用配置。

## 任务内容

1. 理解现有对话流程与格式章程；
2. 将该流程接入资产云，整理为插件 / 可复用配置；
3. 输出一份非技术用户也能看懂的使用说明；
4. 完成一轮测试，记录结果与问题。

## 任务输入

- 原始对话导出文件（报名后提供）
- 格式章程说明
