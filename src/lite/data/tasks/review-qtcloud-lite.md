# 测评量潮云 Lite

## 立题

用统一方法测评量潮云 Lite（lite.cloud.quanttide.com）。对象可替换、目标不换——换一个站点，报告结构不变。

## 定输入

- 站点地址：lite.cloud.quanttide.com（公开可访问，无需后台账号）
- 对照材料：功能列表与仓内 README
- 自理：截图工具、浏览器窄屏调试

## 走步骤

1. 打开首页，记录首屏信息架构：品牌、一句话定位、主行动点各是什么
2. 走一遍主路径（首页 → 最深一层 → 返回），记录每步加载与断点
3. 窄屏 375px 检查移动端适配，同时看控制台有无报错、HTTPS 是否正常
4. 抽查 3 个内容单元，与对照材料比对，记录一致或不一致
5. 按四维打分：信息架构 / 视觉一致 / 内容准确 / 可用性，每维 1–5 分并给证据
6. 写结论：三个可立即修的问题 + 一个亮点

## 交付物

Markdown 测评报告，含四维打分表与「三问题一亮点」，提交至 Issue（引用站点地址与抽查路径）。

## 验收

- [ ] 四维打分齐全，每维有具体证据（截图或路径）
- [ ] 三个问题各含「现象 + 位置 + 建议修法」三段
- [ ] 抽查 3 个内容单元有明确结论（与对照材料一致 / 不一致）

## 报酬

1000 元代金券；也可自报价，最终协商。
