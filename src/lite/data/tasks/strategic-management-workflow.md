# 战略管理工作流搭建

- 业务：量潮品牌
- 类别：战略管理工作流搭建
- 状态：待认领

## 任务背景

量潮把自己定位为「制度创新实验室」。制度创新必然伴随争议：挑战既有做法会触动利益和观念，预期会面临大量质疑、批评甚至攻击。量潮不打算回避争议，而是把争议当作战略资源主动经营——主动进攻。

在此之前，量潮已沉淀两条工作流：批判式公关工作流是矛（主动批评看不惯的现象与制度），评论区侵权取证流水线是盾（遭遇反噬时固定证据、依法维权）。本任务站在战略层，把矛与盾统一到「制度创新实验室」的定位下，回答更根本的问题：哪些争议值得打、打到什么程度、用什么打、打完如何转化为影响力与业务。

## 任务内容

1. 提炼「制度创新实验室」定位下的争议战略：争议不是要回避的风险，而是议题设置与影响力获取的主战场；
2. 设计争议议题决策矩阵：哪些现象值得批判、优先级如何排、预期收益与代价如何评估；
3. 设计矛盾协同规则：何时主动进攻（批判式公关）、何时转入防御（取证流水线）、何时既不接招也不沉默；
4. 设计争议转化漏斗：争议 → 关注 → 共识 → 用户 / 客户 / 盟友，明确每一环节的承接动作；
5. 制定升级与止损标准：争议扩大到什么程度升级、何时撤出话题、底线在哪里；
6. 输出战略管理工作流文档与决策模板，供团队在具体争议发生时按表决策。

## 任务输入

- 公司及创始人相关发文和发帖：公开可见，由接单人自行检索、阅读并总结，量潮不提供素材；
- 批判式公关工作流（矛）与评论区侵权取证流水线（盾）的任务档案及交付物；
- 平台规则、名誉权相关公开判例及公共争议案例资料。

## 交付物

1. 战略管理工作流文档：议题决策、矛盾协同、争议转化、升级止损全流程；
2. 争议议题决策矩阵模板；
3. 矛盾协同规则与升级止损标准清单；
4. 基于假设争议场景的沙盘推演一份（从争议发生到转化落地的完整决策链）；
5. 非技术成员使用说明。

## 评价标准

- 定位一致：全部策略能回溯到「制度创新实验室」定位；
- 矛盾协同：与批判式公关、取证流水线两条工作流衔接顺畅、无职责重叠；
- 可决策：模板拿来即用，团队照表能在争议现场做出判断；
- 转化闭环：争议到业务的转化路径完整可追踪。
