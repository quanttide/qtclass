# 组织管理工作流搭建

- 业务：量潮品牌
- 类别：组织管理工作流搭建
- 状态：待认领

## 任务背景

量潮把自己定位为「制度创新实验室」，并已沉淀三层工作流：战略层统一矛与盾、经营争议；矛是批判式公关，主动批评看不惯的现象与制度；盾是取证流水线，遭遇反噬时依法维权。

这套战略需要组织来承接。团队公开批判机构漠视成员利益，自身就必须经得起同样的审视：社会责任心不是口号，而是制度设计；进取心不能靠自觉，而要有激励与评价支撑。组织本身就是第一张公关牌——「对外批判制度、对内漠视成员」的双标会瞬间摧毁全部公信力。

本任务站在组织层，回答：要塑造一个充满社会责任心和进取心、能承接上述战略的团队，需要设计哪些制度。

## 任务内容

1. 把社会责任心和进取心翻译成可观察、可考核的行为标准，而非停留在价值观口号；
2. 设计选人标准与流程：适配「制度创新实验室」的人是什么样——对现象敏感、对事不对人、能承受争议；
3. 设计激励与评价制度：让进取心有回报、让责任有约束，与任务制和代金券生态衔接；
4. 设计协作与决策机制：与项目复盘工作流衔接，行动项跟踪、责任到人；
5. 制定团队对外行为规范：明确个体言论与组织立场的边界，每个成员在争议场景下都有标准动作；
6. 输出组织管理工作流文档与制度模板，供团队直接落地执行。

## 任务输入

- 公司及创始人相关发文和发帖：公开可见，由接单人自行检索、阅读并总结，量潮不提供素材；
- 既有工作流档案（战略管理、批判式公关、取证流水线、项目复盘）：组织要承接的业务语境；
- 公共方法论文献：组织发展、激励制度、企业社会责任相关公开资料。

## 交付物

1. 组织管理工作流文档：选人、激励、协作、行为规范全流程；
2. 价值观行为化清单：社会责任心与进取心的可观察行为标准；
3. 激励与评价制度模板；
4. 团队对外行为规范：含争议场景下个体发言的边界与标准动作；
5. 基于假设场景的组织沙盘推演一份（如团队陷入争议时的内部响应分工）；
6. 非技术成员使用说明。

## 报酬

1000 元代金券；也可自报价，最终协商

## 其他

- 本任务素材全部来自公司及创始人公开发文和发帖与已公开的任务档案，由接单人自行检索总结，量潮不单独提供材料；
- 双标检验是本任务的强制环节：对外批判采用的标准，必须同样适用于组织自身的制度设计；
- 本任务偏制度设计，不涉及具体人事决策。

## 评价标准

- 价值观可操作：责任与进取都翻译成了可观察行为，无空洞口号；
- 双标检验通过：对外批判的标准同样约束组织自身制度；
- 衔接顺畅：与复盘工作流、战略工作流边界清晰、无缝衔接；
- 可落地：非技术成员照制度能独立执行。
