# 批判式公关工作流搭建

- 业务：量潮品牌
- 类别：公关工作流搭建
- 状态：待认领

## 任务背景

量潮的公关风格是批判式的：嘲讽并批评一切看不惯的现象，但对事不对人。长期实践验证了两条经验：针对现象和机构行为的批评是安全的表达方式；针对具体人的人格权侵害内容会被平台果断处理（实测举报处理率接近 100%）。

批判式公关的典型场景如批评母校漠视学生利益：指向的是机构行为与制度问题，而非任何具体个人。现在需要把这一风格沉淀为可复用、可协作的公关工作流，让团队成员能稳定产出事实扎实、火力集中、合规安全的批判内容，并在遭遇反噬时按标准动作响应。

## 任务内容

1. 检索公司及创始人的发文和发帖，自行阅读并总结风格特征；
2. 梳理批判式公关方法论：如何从看不惯的现象中选题，如何把批评锁定在机构行为与制度层面；
3. 设计事实核验流程：批判建立在可查证的事实上，先固定证据再发声；
4. 制定创作规范与安全线自检：不捏造、不夸大、不侮辱、不指向具体个人，做可代入性检验；
5. 设计发布与传播工作流：渠道选择、发布节奏、舆情监测；
6. 制定响应预案：机构回应、名誉权争议、网暴反扑三种场景的标准动作，衔接评论区侵权「有效取证流水线」；
7. 输出非技术成员能直接使用的操作手册与可公开的批判式表达指南。

## 任务输入

- 公司及创始人相关发文和发帖：公开可见，由接单人自行检索、阅读并总结，量潮不提供素材；
- 统一测试案例：批评母校漠视学生利益（如奖助学金评定不透明、学生反馈渠道失灵、收费争议等），案例素材同样由接单人自行收集整理；
- 评论区侵权「有效取证流水线」方案（legal-evidence 任务交付物），作为响应预案的衔接件；
- 平台规则与名誉权相关公开判例资料。

## 交付物

1. 批判式公关工作流文档：选题、核验、创作、发布、监测全流程；
2. 事实核验清单与「对事不对人」安全线自检表；
3. 舆情响应预案：含与取证流水线的衔接说明；
4. 基于统一测试案例的完整示范内容一条（从选题到发布）；
5. 可公开发布的「批判式表达指南」，教大家安全有效地批评机构与现象；
6. 非技术成员使用说明。

## 报酬

1000 元代金券；也可自报价，最终协商

## 其他

- 本任务素材全部来自公司及创始人公开发文和发帖，由接单人自行检索总结，量潮不单独提供材料，公开层只交付方法论与流程；
- 批判的合规底线：事实可查证、不捏造不夸大、不侮辱人格、不指向机构内具体个人；这既是安全线，也是公信力的来源；
- 工作流必须内嵌该红线作为强制自检环节。

## 评价标准

- 事实核验：示范内容的每个事实性论断均可溯源；
- 火力集中：批评指向行为与制度，无对具体个人的攻击；
- 可复用：非技术成员照手册能独立走完全流程；
- 衔接顺畅：响应预案与取证流水线无缝衔接。
