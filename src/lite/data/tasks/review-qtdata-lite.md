# 测评量潮数据 Lite

## 立题

从技术实现、产品功能、市场推广三个角度测评量潮数据 Lite（lite.data.cloud.quanttide.com）。对象可替换、目标不换——换一个站点，报告结构不变。

## 定输入

- 站点地址：lite.data.cloud.quanttide.com（公开可访问，无需后台账号）
- 对照材料：仓内 README 与 CHANGELOG
- 自理：截图工具、浏览器窄屏调试

## 走步骤

1. 打开首页，记录首屏信息架构：品牌、一句话定位、主行动点各是什么
2. **技术实现**：看加载耗时、HTTPS 与控制台报错；窄屏 375px 查移动端适配；抽查 meta 标签与语义化结构
3. **产品功能**：走一遍主路径（首页 → 最深一层 → 返回），记录断点与迷惑点；抽查 3 个内容单元与对照材料比对
4. **市场推广**：说清目标用户是谁、首屏是否讲明「为谁解决什么问题」；走一遍转化路径（进站到行动有几步、卡在哪）；评估可传播性（能否一键分享、有无可引用的钩子）
5. 三个角度各给 1–5 分并附证据（截图或路径）
6. 写结论：三个可立即改的推广动作 + 一个亮点

## 交付物

Markdown 测评报告，含三角度打分表与「三个可立即改的推广动作」，提交至 Issue（引用站点地址与抽查路径）。

## 验收

- [ ] 三个角度齐全，每条判断有具体证据（截图或路径）
- [ ] 市场推广角度明确说出目标用户与转化卡点
- [ ] 「三个可立即改的推广动作」可直接执行，不含空话
