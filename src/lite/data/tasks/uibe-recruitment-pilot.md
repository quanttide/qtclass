# 对外经济贸易大学招聘宣传合作试点

- 业务：量潮课堂
- 类别：校企合作实践
- 状态：待认领

## 任务背景

公司收到对外经济贸易大学青年科创中心的合作邀请，希望通过其微信公众号及实习社群发布企业介绍和招募信息。

本任务以一轮招聘宣传合作试点为实践场景，学习需求确认、合作沟通、材料整理、发布跟进与效果复盘。

## 任务内容

1. 阅读合作邀请及相关材料，整理合作需求和待确认问题。
2. 确认本轮招募面向公司实习岗位、实训基地实践项目还是两者，明确参与要求和报名方式。
3. 向合作方确认费用、宣传渠道、发布规则、排期及简历接收方式。
4. 整理企业介绍和招募文案，经内部复核后提交合作方。
5. 跟进一轮宣传发布，保存发布链接或截图。
6. 汇总报名、有效简历及后续招募情况，提出继续合作或调整方案的建议。

企业参访、企业课程暂不纳入本次任务范围。

## 任务输入

领取任务后，由需求方提供合作邀请、机构介绍、合作提案及现有招募材料。

合作费用、任务期限、复核与验收安排在执行前确认。

## 交付物

- 合作需求与条件确认记录。
- 经复核的企业介绍、招募文案及报名说明。
- 实际发布链接或截图，以及发布渠道和时间。
- 标明统计周期和口径的招募效果记录。
- 实践总结，包括执行过程、遇到的问题、指导反馈和改进建议。

交付物关联至任务 Issue；涉及邮件原文、简历等内部材料时，仅提供授权可见的记录位置。

## 验收标准

各项成果有真实记录支持，并经需求方验收。未获回复、未能发布或未取得统计数据时，应如实说明原因及处理情况。

发送材料不等于发布成功，提交成果不等于验收通过。

## 如何接任务

通过 Issue 沟通任务领取事宜，后续进度、问题、成果和验收反馈关联至该 Issue。
