# 评论区侵权「有效取证流水线」解决方案设计

- 业务：量潮云
- 类别：招聘考核
- 状态：待认领

## 任务背景

在自媒体平台上，用户常会遇到他人在自己的帖子、视频、动态或笔记评论区发布侮辱、诽谤、恶意攻击内容。当事人如果只截图保存，后续可能面临证据来源不清、内容不完整、无法证明未被篡改等问题。

市场上已有网页取证、手机录屏取证、可信时间戳、区块链存证、公证云类 App 等工具，但普通用户缺少一个清晰的流程：发现评论区侵权后，应该先做什么、用什么工具、按什么顺序操作、最后怎样打包成法院更容易认可的证据材料。

## 任务内容

1. 理解评论区侵权取证中，法院更关注证据的真实性、合法性、关联性；
2. 能区分自行截图、录屏、时间戳、区块链存证、公证保全的效力差异；
3. 能用现成低成本工具设计一条评论区取证流程；
4. 能输出一个可演示、可复用、可交付的解决方案原型。

## 任务输入

- 统一测试案例：原告在某自媒体平台发布一篇帖子，被告在该帖子评论区发布侮辱性言论（例如「脑瘫」「骗子」），并可能引发其他用户跟评、转发或截图传播；原告发现后希望固定证据，用于后续平台投诉、律师函或诉讼；
- 方案围绕该案例设计，但流程本身应能复用到微博评论、小红书笔记评论、抖音视频评论、公众号留言、B站动态评论等类似场景；
- 可用工具范围：手机录屏取证类 App、网页取证/网页快照工具、可信时间戳与区块链存证平台、公证云类服务，以及飞书、Notion、Excel、PDF、Figma、Axure 等文档或原型工具。

## 交付物

1. 取证流程图：覆盖发现评论区侵权、判断平台类型、选择取证工具、执行取证、生成存证凭证、输出证据包至少六个节点，标注每一步的用户动作和工具支持；
2. 工具选择规则表：至少覆盖评论仍在可正常打开、评论已删除但帖子仍在、评论被删除且帖子也可能被删除、评论截图被转发到微信群/朋友圈或其他平台四类场景，每项规则说明适用场景、推荐工具、操作步骤、成本区间、证据效力和风险点；
3. 证据包样例：至少包含原始录屏/截图/网页快照，时间戳或区块链存证凭证，取证过程说明，帖子链接、评论楼层、账号信息与发布时间，点赞/回复/转发等互动数据，证据清单，以及每条证据对应的证明目的；
4. 提交形式不限，任选其一或组合：PDF 解决方案手册、飞书/Notion 工作流页面、Figma/Axure 产品原型、Excel 证据包模板、5 分钟以内演示视频，或流程图 + 工具规则表 + 证据包样例。

## 报酬

1000 元代金券；也可自报价，最终协商

## 其他

- 任务定位：不要求开发新的存证平台，而是把现有低成本工具串起来，形成一套可执行、可复用、可演示的取证解决方案；
- 不要求实际付费购买服务，但需要在方案中说明真实落地时哪些环节会产生成本、单次成本大致处于什么区间；
- 无法接入真实存证平台时，可用占位文件代替，例如「【示例】时间戳证书.pdf」「【示例】区块链存证回执.png」；
- 评价标准：法律有效性 30%、流程完整性 25%、工具串联能力 20%、可操作性 15%、表达与呈现 10%；
- 加分项：设计评论被删除后的应急取证路径；区分平台投诉、律师函、诉讼三种场景的证据要求；提供证据被质疑时的补强方案；给出 0 元、低单价、高可靠性三档成本分级；说明哪些证据更适合走公证、哪些用时间戳/区块链存证即可。

## 学生需要解决的问题

1. 用户发现评论区侵权后，第一步应该做什么？
2. 评论区取证需要固定哪些内容？例如帖子正文、评论楼层、账号主页、时间、点赞回复数、转发情况、群聊二次传播等。
3. 如果评论被删除，应如何补救取证？
4. 如何证明「这条评论确实是该账号发布的」？
5. 如何证明「评论内容指向原告」？
6. 如何降低「截图是P的」「内容被剪辑过」的质疑？
7. 取证完成后，证据包应包含哪些文件？
8. 用户如何把证据用于平台投诉、律师函或诉讼？
