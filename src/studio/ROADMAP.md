# ROADMAP — qtclass-studio

教学与客户面。服务方面（教师 / 管理者）：派任务、盯进度、批改、合稿、排课、跑淘汰赛；客户面（学校、企业、付费个人）：看进度、核课时、收教研记录、对交付——v0.2 客户面极简只读。

现状：Flutter，v0.1.9 已发布（`studio.class.quanttide.com`）；课表、课堂、播放器、学员登录、学习入口。旧 `/progress`、`/proposals` 入口已暂停（上游重构移除）。
