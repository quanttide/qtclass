# 首页 (home.html)

课程首页，作为用户进入互动式课程学习的第一入口。

## 页面定位

- **路由**: `/` 或 `/home.html`
- **状态**: 独立页面，通过链接跳转到 `player.html`
- **数据依赖**: 无（纯静态展示，仅在导航按钮上根据 localStorage 状态可改为"继续学习"）

```
┌─ home-nav (顶栏导航) ──────────────────────┐
│  [量潮课堂]                    [课程首页]    │
└────────────────────────────────────────────┘
│                                             │

│                                             │
│  Python 基础：第一个 Python 程序             │
│  副标题说明文案                              │
│                                             │
│  ┌──────────┬──────────┬──────────┬────────┐│

│  └──────────┴──────────┴──────────┴────────┘│
```

## 组件清单

| 组件 | 选择器/ID | 说明 |
|------|-----------|------|
| 导航栏 | `.home-nav` | 品牌标识 + 导航链接（课程首页） |
| 内容容器 | `.home-content` | 垂直居中布局，max-width: 680px |
| 课程标签 | `.home-tag` | 课程分类与类型标识 |
| 标题 | `h1` | 课程名称 |
| 副标题 | `.home-subtitle` | 课程简介文案 |
| 元信息行 | `.home-meta-row` | 适合人群、预计时间、选择节点、课程难度 |
| 方法标签 | `.home-method` | 互动式方法关键词 |
| 学习目标 | `.home-objectives-list` | 勾选列表，展示本节学习目标 |
| 开始按钮 | `.home-btn-primary` | 跳转到 `player.html` 或恢复学习 |

## 交互与导航

| 交互 | 触发条件 | 行为 |
|------|---------|------|
| 开始学习 | 用户无进度 | 跳转 `player.html`（新用户） |
| 继续学习 | localStorage 有保存记录 | 跳转 `player.html?resume=true`（回访用户） |

## 设计原则

1. **信息密度适中** — 展示足够让用户做出"是否开始"决策的信息，不过度
2. **CTA 突出** — 主按钮使用品牌色（`--accent`），视觉层级最高
3. **进度感知** — 根据用户是否已有学习进度，按钮文本在"开始学习"/"继续学习"之间切换
4. **响应式** — 760px 以下按钮全宽堆叠，元信息行减少间距

## 状态机

```
[无进度] ──点击"开始学习"──→ [player.html]
                                    │
                                    ↓  (学习完成后返回首页)
[有进度] ──点击"继续学习"──→ [player.html?resume=true]
```
