# 首页 (home.html)

课程首页，作为用户进入互动式课程学习的第一入口。

## 页面定位

- **路由**: `/` 或 `/home.html`
- **状态**: 独立页面，通过链接跳转到 `player.html`
- **数据依赖**: 无（纯静态展示，仅在导航按钮上根据 localStorage 状态可改为"继续学习"）

## 组件清单

| 位置 | 组件 | 类型 | 说明 |
|------|------|------|------|
| 顶部栏 | `HomeNavBar` | 页面导航 | 品牌标识 + 导航链接（课程首页） |
| 整页容器 | `HomeContent` | 页面容器 | 垂直居中滚动布局，包裹下方全部内容，内容区 max-width: 680px |
| 标题区 | `CourseTag` | 展示组件 | 课程分类与类型标识（最上方小标签） |
| 标题区 | `CourseTitle` | 展示组件 | 课程名称（主标题） |
| 标题区 | `CourseSubtitle` | 展示组件 | 课程简介文案（副标题） |
| 元信息行 | `MetaRow` | 布局组件 | 一行四列：适合人群、预计时间、选择节点、难度（子项 `MetaItem`） |
| 目标上方 | `MethodLabel` | 展示组件 | 互动式方法关键词 |
| 目标列表 | `ObjectivesList` | 列表组件 | 勾选列表，展示本节学习目标（子项 `ObjectiveItem`） |
| 底部 CTA | `StartButton` | 交互组件 | 跳转播放器或恢复学习，无进度/有进度切换文案 |

## 交互与导航

| 交互 | 触发条件 | 行为 |
|------|---------|------|
| 开始学习 | 用户无进度 | 跳转 `player.html`（新用户） |
| 继续学习 | localStorage 有保存记录 | 跳转 `player.html?resume=true`（回访用户） |

## 设计原则

1. **信息密度适中** — 展示足够让用户做出"是否开始"决策的信息，不过度
2. **CTA 突出** — 主按钮使用品牌色（`--accent`），视觉层级最高
3. **进度感知** — 根据用户是否已有学习进度，按钮文本在"开始学习"/"继续学习"之间切换
4. **响应式** — 760px 以下按钮全宽堆叠，元信息行减少间距

## 状态机

```
[无进度] ──点击"开始学习"──→ [player.html]
                                    │
                                    ↓  (学习完成后返回首页)
[有进度] ──点击"继续学习"──→ [player.html?resume=true]
```
