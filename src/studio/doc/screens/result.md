# 结果页 (result.html)

课程完成后的学习路径总结页面，展示用户本次学习的选择结果。

## 页面定位

- **路由**: `/result.html?env=windows|macos|linux`
- **状态**: 通过 URL query parameter `env` 接收上游状态
- **数据依赖**: 仅依赖 URL 参数，不读取 localStorage
- **设计理念**: 作为课程完成的"终点"页面，展示分支路径结果并引导继续学习

## 页面结构

```
┌─ result-nav (顶栏导航) ────────────────────┐
│  量潮课堂                     [← 返回首页]  │
└───────────────────────────────────────────┘
│                                            │
│  分支结果 · 学习路径生成                   │
│                                            │
│  你的 Python 学习路径已生成                 │
│  根据你的设备环境，我们调整了对应...        │
│                                            │
│  ┌─────────────────────────┐              │
│  │  ✓           ✓        → │              │
│  │ 开启学习    选择环境   解锁成功运行     │
│  └─────────────────────────┘              │
```

## 组件清单

| 组件 | 选择器/ID | 说明 |
|------|-----------|------|
| 导航栏 | `.result-nav` | 品牌标识 + 返回首页链接 |
| 标签 | `.result-tag` | "分支结果 · 学习路径生成" |
| 标题 | `h1` | "你的 Python 学习路径已生成" |
| 描述 | `.result-desc` | 路径说明文案 |
| 路径可视化 | `.result-path` | 3 节点进度条 (完成/完成/待解锁) |
| 信息卡片1 | `#resultEnvDisplay` | 用户选择的环境信息 |
| 信息卡片2 | `#resultToolDisplay` | 当前阶段描述 |
| 继续按钮 | `#resultContinueBtn` | 引导进入下一课程 |

### 路径可视化详情

路径包含 3 个节点，用连线连接：

| 节点 | 状态 | 表示 |
|------|------|------|
| 开启 Python 学习任务 | `.done` | 绿色勾 ✓ |
| 选择运行环境 | `.done` | 绿色勾 ✓ |
| 解锁第一次成功运行 | `.next` | 脉冲动画 → |

注意：此处结果页展示的路径比播放器侧边栏（5 步）做了简化合并，以避免信息冗余。播放器中两个分支步骤（环境选择 + 运行状态选择）在此合并为"选择运行环境"一个节点。

## 数据流

```
player.html (finishLesson)
       │
       │  URL 跳转 (或内嵌显示)
       ▼
result.html?env=windows
       │
       │  读取 URL param
       ▼
       env = "windows"
       → { envDisplay: "Windows 运行环境", toolDisplay: "解锁第一次成功运行" }
```

## 交互

| 交互 | 触发 | 行为 |
|------|------|------|
| 返回首页 | 点击导航栏"← 返回首页" | 跳转 `home.html` |
| 继续学习 | 点击"继续学习"按钮 | 弹出 toast 提示"下一课程即将上线" |

## 设计原则

1. **清晰的结果呈现** — 不同于播放器内复杂的状态管理，结果页专注于展示学习路径的摘要
2. **视觉反馈** — 完成节点使用品牌色 + 勾选标记，待解锁节点使用脉冲动画引导注意力
3. **渐进式信息** — 先展示路径概览，再展示详细信息卡片
4. **轻量依赖** — 仅需 URL 参数，不依赖 localStorage，降低耦合
5. **可扩展** — 后续可增加更多统计信息（用时、正确率、推荐下一课程等）
