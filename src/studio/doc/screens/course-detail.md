# 课程详情页（展示 · course-detail）

量潮课堂客户端的课程详情展示页，包含**课程首页（Hero）**和**课时列表**两部分。课时条目点击后进入播放器（`player.html`），与客户端现有 `home.html` / `player.html` 播放链路衔接。对应实验室原型课程详情页（`view-front` / `view-generic`）。

## 页面定位

- **路由**: `course-detail.html?course=<id>`，从课程列表页点击进入
- **状态**: 两种形态 — 生产实习专用（`view-front` 风格，5 模块）与通用课程模板（`view-generic` 风格，按课程阶段渲染）
- **数据依赖**: 课程数据来自 qtcloud-course 供给；进度读写 `localStorage('qt-progress-<courseId>')`
- **来源**: 实验室原型 [course-detail.md](https://github.com/quanttide/quanttide-laboratory-of-course-development/blob/main/innovation-prototype/screens/course-detail.md)

## 交互与导航

| 交互 | 触发条件 | 行为 |
|------|---------|------|
| 点击课时条目 | `.lesson-item` | 跳转 `player.html?course=<id>&lesson=<lessonId>`（客户端播放器，见 [player.md](player.md)） |
| 点击步骤节点 | 步骤条 `.step` | 切换到对应模块面板 |
| 点击"继续学习" | Hero 中 | 有进度跳到最后完成的下一步，无进度跳到阶段 1 |
| 点击"→ 下一模块" | 模块底部 | 切换下一面板，`updateStepBar()` + `saveProgress()` |
| 点击"← 返回课程首页" | 模块底部 | 回到 Hero，隐藏步骤条 |
| 点击"← 返回课程列表" | 顶部 `.back-link` | 回到课程列表页 |
| 点击"→ 进入下一课程" | 最后模块底部 | 跳到下一门课首页（课程 1-4 阶梯串联） |
| 播放器返回 | `player.html` 返回 | 回到对应课时所在模块，进度已回写 |

## 进度持久化

与实验室原型一致（详见 [course.md](https://github.com/quanttide/quanttide-laboratory-of-course-development/blob/main/innovation-prototype/models/course.md)）：

| 课程 | 存储键 | 格式 |
|------|--------|------|
| 生产实习 | `qt-progress-prod` | `{"max":3,"last":"m3"}` |
| 课程 1-4 | `qt-progress-<courseId>` | `{"max":2,"last":"s2"}` |

**关键规则**：`last` 为 `undefined` 时显示课程首页（Hero）；`max` 只增不减；每门课独立存储。课时播放进度由播放器回写同一存储。

## 设计原则

1. **一屏一模块** — 课程首页 Hero 控制在一屏内，模块面板独立切换
2. **进度可视化** — 步骤条（圆点颜色）+ 进度条（蓝色填充）双重反馈
3. **展示与播放分离** — 本页只做内容浏览与导航，课时播放统一交给 `player.html`（qtclass 播放器职责）
4. **双轨渲染** — 生产实习硬编码（内容定制化强），通用课程共用模板（动态渲染），共享同一套 CSS 组件体系
5. **状态恢复** — 重新打开时自动回到上次学习的模块

## 状态机

```
[课程列表] --点击课程--> [course-detail]
                             |
                  根据进度进入 Hero 或上次模块
                             |
        +--------------------+---------------------+
        |                                          |
   [课程首页 · overview]                    [模块 N · 课时列表]
        |                                          |
   "继续学习" / 步骤节点                     点击课时条目
        |                                          |
        v                                          v
   [模块 N+1] --> ... --> [最后模块]      [player.html 播放器]
                              |                  |
                       "进入下一课程"       返回（进度已回写）
                              |                  |
                              v                  v
                    [下一门课详情]         [回到模块 N]
```
