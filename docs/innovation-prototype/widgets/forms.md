# Forms — 表单组件

数据输入相关组件，用于立项申请、审批、咨询等场景。

---

## 1. FormGroup — 表单字段组

| 属性 | 值 |
|------|-----|
| 选择器 | `.form-group` |
| 下边距 | `margin-bottom: 16px` |

**子元素**：`label`（13px 粗体，`margin-bottom: 6px`）+ 输入控件

**使用位置**：后台立项申请表、阶段报告模板、验收评审表、生产实习模块 5

---

## 2. Input — 文本输入框

| 属性 | 值 |
|------|-----|
| 选择器 | `input[type=text]`（也适用于 `input` 通用） |
| 样式 | `width: 100%`，`padding: 10px 14px`，1.5px 浅灰边框，圆角 8px，`background: var(--surface)` |

**状态**：
| 状态 | 触发 | 视觉 |
|------|------|------|
| 默认 | — | 浅灰边框 |
| `:focus` | 聚焦 | 边框变蓝 `border-color: var(--brand)`，outline:none |
| `:focus-visible` | 键盘聚焦 | 2px 蓝色 outline + 2px offset |

**使用位置**：项目名称输入、咨询主题输入

---

## 3. Textarea — 多行文本

| 属性 | 值 |
|------|-----|
| 选择器 | `textarea` |
| 最小高度 | `min-height: 90px` |
| 缩放 | `resize: vertical` |
| 其余样式 | 与 Input 一致 |

**使用位置**：盲区/机会描述、Demo 方案描述、审批意见、咨询详细描述

---

## 4. Select — 下拉选择

| 属性 | 值 |
|------|-----|
| 选择器 | `select` |
| 样式 | 与 Input 一致 |
| 选项 | `option` 子元素 |

**选项列表**：

| 场景 | 选项 |
|------|------|
| 方向类型 | 技术探索 / 产品构建 / 商务拓展 / 组织创新 |
| 组队方式 | 个人独立 / 已找好搭档 / 希望在组队广场招募 |
| 资源等级 | 基础级 / 支持级 / 重点级 |
| 报告阶段 | 阶段一：立项启动 / 阶段二：中期检查 / 阶段三：成果验收 |
| 帮助需求 | 无需帮助 / 需要导师指导 / 需要资源支持 |
| 进度评估 | 超前 / 正常 / 滞后 |
| 验收结论 | 通过验收 / 有条件通过 / 不通过 |
| 评分 | 1-5 分 |
| 问题类型 | 技术问题 / 产品/业务问题 / 职业发展建议 / 课程内容疑问 / 其他 |
| 紧急程度 | 一般 / 较急 |

**使用位置**：立项申请表、审批中心、阶段报告、验收评审表、咨询表单

---

## 5. Radio — 单选按钮

| 属性 | 值 |
|------|-----|
| 选择器 | `input[type=radio]` |
| 强调色 | `accent-color: var(--brand)` |

**使用位置**：立项申请表预览页（form-page），题目选项
