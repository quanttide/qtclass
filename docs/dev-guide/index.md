# 量潮课堂产品定位

## 一句话定位

> **面向培训机构的情景式互动教学平台**：用分支视频做内容，用班级制管教学，按学期收费用。

## 产品边界

```
qtclass（课堂平台）     ← 面向用户的产品，编排云服务完成教学闭环
├── 依赖 qtcloud-auth    ← 身份云：登录、Token、用户信息
├── 依赖 qtcloud-course  ← 课程云：课程体系、互动内容、班级管理
└── 依赖 qtcloud-pay     ← 支付云：订单、查询、退款
```

qtclass **不拥有**领域数据和业务逻辑——这些由各云服务提供。qtclass 作为产品层，将云服务编排为教师和学员可见的完整教学体验。

## 核心用户与场景

### 教师（前台）
- 备课：创建课时，编排互动视频场景（Scene）和分支选项
- 开课：创建班级（Class），设定学期起止时间
- 授课：推进教学进度，管理课堂

### 学员（前台）
- 报名：查看课程，支付报名费
- 上课：观看互动视频，在分支节点做出选择
- 结课：跟随班级完成学习周期

### 运营管理员（后台）
- 课程体系管理：Program → Course → Lesson → Scene 的层级配置与关联
- 班级运维：创建、状态变更（preparing → active → ended）、删除
- 用户管理：管理员认证、权限
- 支付管理：订单查询、退款处理

## 关键特征

| 特征 | 说明 |
|------|------|
| **班级制** | 班级有完整生命周期和进度追踪，非卖课模式 |
| **互动视频** | Scene 为最小教学单元，支持分支选择，非线性播放 |
| **按班收费** | 支付发生在班级维度，非课时也非会员 |
| **云服务架构** | 领域能力下沉到各 qtcloud-* 服务，qtclass 专注编排 |

## 内容层级

```
Program（专业）    → 大数据微专业
  └── Course（课程）  → Python 数据科学
       └── Lesson（课时） → Pandas 基础
            └── Scene（场景） → 视频片段 + 分支选项
```

Class（班级）是教学实施单元，引用一个 Program 或 Course，独立管理学期和进度。
